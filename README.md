# 重邮新生导引 · 南山第一程

非官方新生导引概念原型。一个晴天浅绿、可驾驶的低多边形 3D 校园：从校门出发，沿南山路经过报到大厅、宿舍区、一卡通中心、教学区、校医院、快递站和食堂，开进光圈查看办理步骤。

- `W A S D` / 方向键驾驶，`E` 查看，`R` 回校门，`Esc` 关闭
- 手机使用左下虚拟摇杆
- 顶部「直接看清单」不驾驶也能看全部站点
- 路尽头的终点会在 3 秒后跳转重邮教务在线；顶部/清单可打开学校可视化地图
- 部分校内系统与地图可能需要校园网或 VPN

内容依据公开迎新资料整理，具体流程、地点与时间以学校官方通知、辅导员及教务系统为准。本页不是学校官方网站，不接入教务、迎新或导航系统数据。

纯 HTML / CSS / JavaScript，three.js r128 本地引入，无构建步骤。
